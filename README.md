# Thogakade Shop Management System - JavaFX

A comprehensive shop management system built with JavaFX for retail businesses. This application provides an intuitive interface for managing products, customers, orders, and inventory with real-time updates and reporting capabilities.

## 📋 Project Overview

Thogakade is a desktop-based shop management system designed to streamline retail operations. It offers complete CRUD functionality for inventory management, customer relationship management, and order processing with a modern JavaFX user interface.

## ✨ Key Features

Dashboard

Real-time sales overview

Low stock alerts

Today's transactions summary

Quick access to all modules

### Product Management

Add new products with details (name, price, quantity, category)

Update product information

Delete products from inventory

Search products by name/category

Barcode generation support

Stock level tracking

### Customer Management

Customer registration and profiles

Purchase history tracking

Loyalty points system

Customer search and filtering

Contact information management

### Order Processing

Create new sales orders

Add multiple items to cart

Calculate totals automatically

Generate receipts

Print invoices

Order history view

### Inventory Management

Real-time stock updates

Low stock notifications

Stock adjustment functionality

Supplier information


## 🛠️ Technologies Used

Java - Core programming language (JDK 8+)

JavaFX - Rich client application framework

Scene Builder - FXML UI design tool

FXML - XML-based UI markup

CSS - Application styling

MySQL/PostgreSQL - Database management

JasperReports - Report generation

Maven/Gradle - Dependency management
